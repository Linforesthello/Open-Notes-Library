
## 多文件/文件夹体系下，单文件/单文件夹回退
[Git回退单个文件](https://chatgpt.com/c/69a67c05-7220-8320-9e34-488b993a6ac9)

> [!NOTE]
> # ⚠️ 还有一个隐藏问题
> 
> 你现在仓库结构是：
> 
> STM32_Now  
>  ├── 3_MotorControl_LowMachine  
>  ├── 5_Tec_USART  
>  ├── 6_LED_PC13_
> 
> 这意味着：
> 
> 你多个实验共用一个仓库
> 
> 这会导致：
> 
> - 改一个实验
>     
> - 另一个实验也被算作修改
>     
> 
> 长远来看我强烈建议你：
> 
> 👉 每个实验一个仓库  
> 或  
> 👉 每个实验一个分支
> 
> 否则以后你会被版本管理拖死。
