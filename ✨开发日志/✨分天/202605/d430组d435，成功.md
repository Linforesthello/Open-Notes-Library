## rviz2看不到点云
![[Pasted image 20260622210101.png]]
```
ros2 launch realsense2_camera rs_launch.py   pointcloud.enable:=true   pointcloud.allow_no_texture_points:=true   align_depth.enable:=true
```
可以看到点云，但是rgb8没有颜色


```
source /opt/ros/humble/setup.bash
ros2 launch realsense2_camera rs_launch.py \
  pointcloud.enable:=true \
  pointcloud.allow_no_texture_points:=true \
  align_depth.enable:=true

```
