> [!NOTE]
> 很好，这就更明确了——你现在有三类东西：
> 
> - `HomeWiFi`
> - `HomeWiFi 1`
> - `profile 1` ← 这个是**系统自动生成的默认连接名**
> 
> 👉 结论先说：  
> **`profile 1` 也是一个连接配置残留，直接删，不用犹豫。**
> 
> ---
> 
> # 🧠 一、为什么会出现 `profile 1`
> 
> 在 NetworkManager 里：
> 
> 当系统在以下情况下会创建这种名字：
> 
> - 没有明确SSID匹配
> - 你手动改过IP/接口
> - 或配置损坏 / 不完整
> 
> 👉 就会生成：
> 
> ```
> profile 1profile 2
> ```
> 
> 本质就是：**“临时救急配置”**
> 
> ---
> 
> # 🔥 二、正确清理顺序（推荐一步到位）
> 
> 先看全部连接：
> 
> ```
> nmcli connection show
> ```
> 
> ---
> 
> ## ✅ 删除所有异常配置
> 
> ```
> sudo nmcli connection delete "HomeWiFi 1"sudo nmcli connection delete "profile 1"
> ```
> 
> 如果还有：
> 
> ```
> sudo nmcli connection delete "profile 2"
> ```
> 
> ---
> 
> ## ⚠️ 如果你不确定哪个是干净的（更稳做法）
> 
> 👉 直接全部删 WiFi 相关：
> 
> ```
> nmcli connection show | grep wifi
> ```
> 
> 然后全删：
> 
> ```
> sudo nmcli connection delete "<名字>"
> ```
> 
> ---
> 
> # 🔄 三、重新建立“唯一正确连接”
> 
> ```
> nmcli device wifi connect "HomeWiFi" password "你的密码"
> ```
