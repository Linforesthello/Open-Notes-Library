> [!NOTE]

> 我给你一套**最实用快捷键（默认配置）**👇
> 
> ---
> 
> # 🔥 一、分屏（核心操作）
> 
> ### ✅ 垂直分屏（左右）
> 
> ```
> Ctrl + Shift + O
> ```
> 
> ### ✅ 水平分屏（上下）
> 
> ```
> Ctrl + Shift + E
> ```
> 
> 👉 记忆方式：
> 
> - **O = Vertical（像一根竖线）**
>     
> - **E = Horizontal（像横线展开）**
>     
> 
> ---
> 
> # 🔥 二、在分屏之间移动（非常重要）
> 
> ```
> Alt + ↑ / ↓ / ← / →
> ```
> 
> 👉 在不同终端之间切换焦点
> 
> ---
> 
> # 🔥 三、关闭当前分屏
> 
> ```
> Ctrl + Shift + W
> ```
> 
> ---
> 
> # 🔥 四、调整分屏大小
> 
> ```
> Ctrl + Shift + ↑ / ↓ / ← / →
> ```
> 
> 👉 动态调整窗口比例（这个在调 CAN / ROS log 特别爽）
> 
> ---
> 
> # 🔥 五、复制 & 粘贴（避免鼠标）
> 
> ```
> Ctrl + Shift + C   # 复制
> Ctrl + Shift + V   # 粘贴
> ```
> 
> ---
>
