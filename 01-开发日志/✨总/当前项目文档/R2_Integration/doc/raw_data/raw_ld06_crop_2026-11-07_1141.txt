# 结论（2026-11-07）：
# 1) crop 生效：两个用例都出现 ~90.6° 的连续 NaN 带（112~115 bin），
#    其余 NaN 为无回波散点（3~13 bin 小段）。
# 2) 参数坐标 = 雷达原始角（度，闭区间）：
#    crop [135,225] → 发布角 [134.3,225.7]（对称带，两种约定重合）
#    crop [0,90]   → 发布角 [269.4,360.8]（镜像）⇒ 发布角 = 360° − 原始角
#    该镜像由 laser_scan_dir=true 时驱动反向填数组造成（demo.cpp L214-225）。
# 3) 掩盖带宽度 ≈ 90.6°，比名义 90° 多约 1 个 bin（ceil 索引 + 区间端点含入 + 角量化）。
# 4) 消息长度不变（453/454），angle_min/max 仍 0/360——crop 只把值置 NaN，
#    下游（slam_toolbox / costmap）按"无回波"处理；不会缩短扫描范围。
# 5) 配置换算：要掩盖发布角 [α1,α2]，crop 设 [360−α2, 360−α1]；对称于 180° 的带两种写法一致。
