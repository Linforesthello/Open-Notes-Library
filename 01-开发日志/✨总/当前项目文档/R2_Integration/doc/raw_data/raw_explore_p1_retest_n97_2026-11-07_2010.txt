六、后加判读（非原始输出）
----------------------------------------------------------------
1. **P1 冲突裁定：上游正确，本地文档（explore-plan §3.1.2 / explore_params.yaml /
   raw_explore_smoke_...txt 判读）结论错误。**
   `return_to_init` 存在且可取；7 参数是 declare_parameter（不是 get_parameter_or）。

2. **首次冒烟假阴性的根因 = 三个顺序阻塞点，参数声明被挡在构造链后段：**
   ① costmap_client.cpp:89  等 costmap（无 Nav2 时永不返回）
   ② costmap_client.cpp:~118 等 map→base_link TF
   ③ explore.cpp:112        等 NavigateToPose action server（无超时）
   阻塞点①②在 Costmap2DClient 构造函数内 → Explore 构造函数体（含 8 个 declare）不执行；
   阻塞点③在 declare 之后，但节点不 spin → 参数服务不可用。
   → 结论：**explore_lite 无法在"只有雷达"的裸环境下用 param list 验证参数**。

3. 另一个 session §2.3 给的三个假设（同名残留 / overlay 串台 / daemon 缓存）均不成立：
   本次复测已先 `ros2 daemon stop`、只 source 目标工作区、A/B 同一进程对照。

4. 副产物：`ros2 topic pub --once` 在 DDS 发现完成前发送会丢消息（volatile），
   对已在等待的订阅者要用 `-r 1` 连续发。

5. 设备状态：本次启动的 explore / static_transform_publisher / fake action server
   已全部 kill（ps -p 复核"全部已退出"），`ros2 daemon stop` 已执行。
