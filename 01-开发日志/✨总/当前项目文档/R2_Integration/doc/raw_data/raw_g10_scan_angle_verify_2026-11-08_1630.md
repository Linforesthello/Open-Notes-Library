## 五、换算与拟合（AI 本地计算，逐字）

作为箱面的是 **83.63°~104.34°** 段（`car_x` 恒定的那条）。拟合结果：

```text
面拟合 x = 1.2656 + -0.0369*y   (斜率 -0.0369, 倾角 -2.11 deg, 残差RMS 0.8 cm)
y 跨度 0.178 ~ 0.544 m  ->  宽 0.366 m, 中心 y=0.358 m
面到雷达光心垂距 = 0.991 m
  假设箱面 x=1.25 且居中于车中线(y=0): theta = 73.4 deg
  假设箱面 x=1.48 且居中于车中线(y=0): theta = 76.5 deg
  实测箱面中心 y=0.358: theta = 94.0 deg
```

角度换算式（车体系 → `/scan` 发布角）：

```text
θ /scan = atan2(x_car − 0.275, 0.290 − y_car)
```

## 六、判定

| # | 判据 | 实测 | 结论 |
|:--|:---|:---|:---|
| 1 | 箱面应垂直于车体 +x（yaw 正确时呈一条 x 恒定的直线） | `x = 1.266 − 0.037·y`，倾角 **−2.1°**，残差 0.8 cm | ✅ yaw=−90° 成立（误差 ≲2°，含箱子手摆） |
| 2 | 箱面应在车头侧（排除 ±90° 的 180° 反号） | 面在 **x=+1.27 m** | ✅ 车头方向 |
| 3 | 若镜像假设错（发布角=原始角），前方物体会在 270° | 267°~335° 只有 0.10~0.15 m 车体回波，无 1 m 箱面 | ✅ 镜像假设成立 |
| 4 | 尺寸/距离自洽 | 面宽 **0.366 m**（350 mm 箱 + 两侧半波束）、垂距 **0.991 m**（"1 m 左右"） | ✅ |

**结论：`yaw = −1.5708 rad` 实物复核通过；`/scan` 的 +90° 方向 = 从雷达光心出发的车体 +x 方向。**

**口径修正（重要）**：雷达装在 `y=+0.29`，所以*车体中线*上的目标读 **≈73°**（x=1.25 时），
不是 90°；只有摆在**雷达正前方那条线**（y≈0.29）才读 90°。原文档"目标放车正前方应读 +90°"
的表述据此修正，避免下次复核误判。

## 七、复核方法（可复用，LD06 #2 / 新车雷达照做）

1. 车头/雷达前方约 1 m 摆一个**正面平齐**的箱（已知宽度最好），箱面朝向车体；
2. 确认 `/scan` 的 `frame_id / angle_min / angle_max / angle_increment`（本驱动为 0~360°、0.7965°）；
3. 取**最近角段**逐波束 `(r, θ)`，按 `x = 0.275 + r·sinθ`、`y = 0.290 − r·cosθ` 换算车体系；
4. 判据 = ① 落在一条 `x≈常数` 的面上（倾角 ≲2°）② 面在车头侧 ③ 宽度/距离与实物自洽
   → 通过；若目标整体出现在 −90°/0°/180°，才是 △ 朝向或镜像假设有误。

探针脚本（本次在 N97 `/tmp/scan_angle_probe.py` 与 `/tmp/scan_angle_detail.py`，重启后可能丢失；
如需常驻可考虑提升为 `scripts/` 工具——本次未落仓）：

```python
import math, rclpy
from sensor_msgs.msg import LaserScan
OX, OY = 0.275, 0.290          # 雷达在 base_link 系的位置

def car_xy(r, a_deg):
    a = math.radians(a_deg)
    return OX + r * math.sin(a), OY - r * math.cos(a)

rclpy.init()
node = rclpy.create_node('scan_angle_probe')
msgs = []
node.create_subscription(LaserScan, '/scan', lambda m: msgs.append(m), 10)
while len(msgs) < 3 and rclpy.ok():
    rclpy.spin_once(node, timeout_sec=1.0)
m = msgs[-1]
pts = [(r, math.degrees(m.angle_min + i * m.angle_increment))
       for i, r in enumerate(m.ranges) if math.isfinite(r) and m.range_min < r < m.range_max]
for r, a in sorted(pts)[:10]:
    print(f"r={r:6.3f} theta={a:+8.2f} -> car {car_xy(r, a)}")
node.destroy_node(); rclpy.shutdown()
```
