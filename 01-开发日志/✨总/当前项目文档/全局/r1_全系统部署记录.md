## 四、CAN 总线

### 硬件

- CANable2 (固件: slcan, 1Mbps)
- 4× MCLM_t2 电机控制器板
- 每板控 2 电机: 转向 + 驱动
- 波特率: 1Mbps (slcand -s8)

### CAN ID 映射（实测 2026-07-13）

| 单元 | 物理位置 | 转向 CMD | 驱动 CMD | 转向状态 | 驱动状态 | TICKS_PER_REV |
|:----:|:--------:|:--------:|:--------:|:--------:|:--------:|:-------------:|
| UNIT1 | 右后 | 0x121 | 0x122 | 0x321 | 0x322 | 9218 |
| UNIT2 | 右前 | 0x123 | 0x124 | 0x323 | 0x324 | 9196 |
| UNIT3 | 左前 | 0x125 | 0x126 | 0x325 | 0x326 | 7844 |
| UNIT4 | 左后 | 0x127 | 0x128 | 0x327 | 0x328 | 9395 |

### 状态帧格式

```
[0-1] current_logic_speed (int16 LE)
[2-3] accumulated_ticks   (uint16 LE)  → 转向角度
[4-5] pwm_output          (int16 LE)
[6]   target_logic_speed  (int8)
[7]   flags               (uint8)      → 0x01=堵转, 0x02=PWM饱和
```

## 五、底盘运动学

### 公式

```python
# inv_kinematics: 车体速度 → 各单元转向角度+驱动速度
v_ix = vx - omega * y
v_iy = vy + omega * x
steer = -atan2(v_iy, v_ix)     # 取反对齐电机方向
drive = hypot(v_ix, v_iy)
```

### WHEEL_POS

```python
WHEEL_POS = [
    (-0.25, -0.30),   # UNIT1: 右后
    ( 0.25, -0.30),   # UNIT2: 右前
    ( 0.25,  0.30),   # UNIT3: 左前
    (-0.25,  0.30),   # UNIT4: 左后
]
```

### 坐标约定

- x⁺ = 前进方向（车头）
- y⁺ = 左侧方向
- ω > 0 = 右转 (CW)

### 电机方向修正

```
运动学输出: +角度 = 逆时针(向左)
电机物理:   +speed = 顺时针(向右)
```

修正方式：
1. `inv_kinematics()` 中 `steer = -atan2(...)` 取反角度
2. `set_speed()` 中 `speed = -speed` 取反转向命令
3. `angle_now()` 中 `angle = -(raw/rev)*360` 取反角度计算

**三个取反缺一不可，否则 PID 发散 → 电机堵转 → 烧毁！**

## 六、控制参数

### PID

| 参数 | 值 | 说明 |
|:----|:---|:------|
| KP_ANGLE | 1.0 | 比例增益 |
| KI_ANGLE | 0.03 | 积分增益 |
| DEAD_ZONE_DEG | 0.5° | 转向死区 |
| STEER_READY_DEG | 5.0° | 舵向就绪阈值（到位才允许驱动） |
| MAX_STEER_SPEED | 60 | 最大转向速度 |
| STEER_RAMP_RATE | 8 | 转向速度变化率限幅 |

### 保护

| 保护 | 参数 | 行为 |
|:----|:-----|:-----|
| 堵转保护 | 2.0s | PWM 饱和 + 速度=0 超过 2s 自动切断 |
| 舵向超时 | 2.0s | 舵向 2s 未到位，强制输出驱动 |
| 遥控超时 | 1.0s | 串口数据中断 1s，全车急停 |
| 角度限幅 | ±90° | PID 误差最大 ±90°，防止冲向限位 |
| 速率限制 | ±8/cycle | 转向速度突变限制 |

## 七、遥控方案

### 主通道：E34 无线串口

```
Windows PC → USB→J-Link → E34模块
  → 2.4GHz无线 → E34模块 → J-Link → Mini PC /dev/ttyACM1
  → serial_reader → apply_remote_command() → CAN → 底盘
```

- 波特率: 115200
- 协议: 文本行 `vx vy omega\n` + 命令 `cal`/`stop`/`steer N`
- 超时保护: 1s 无数据自动急停

### 辅通道：TCP (待实现)

- 监听端口 5000
- 支持同格式文本指令
- 受手机热点质量影响，不用于安全关键控制

### 键盘映射

| 按键 | 动作 | 发送值 |
|:----|:-----|:-------|
| W | 前进 | `0.30 0.00 0.00` |
| S | 后退 | `-0.30 0.00 0.00` |
| A | 左移 | `0.00 0.30 0.00` |
| D | 右移 | `0.00 -0.30 0.00` |
| Q | 左转 | `0.00 0.00 -0.30` |
| E | 右转 | `0.00 0.00 0.30` |
| Space | 急停 | `0.00 0.00 0.00` |
| ESC | 退出 | — |

### 发送频率

- 200ms 一次 (5Hz)
- 持续发送当前按键状态，松手自动停

## 八、操作流程

### 上电启动

```bash
# 终端 1: 启动 CAN
sudo ~/r1_control/can_up.sh

# 终端 2: 启动控制程序
cd ~/r1_control && source bin/activate
sudo python3 pi_chassis_control.py
# 启动时选择串口设备:
#   /dev/ttyACM0 = CANable2
#   /dev/ttyACM1 = E34 无线串口

# 控制台输入:
cal         # 归零
remote      # 启用遥控模式
# 现在 Windows 键盘可以控制
```

### 遥控端 (Windows)

```cmd
conda activate r1
python keyboard_control.py
```
