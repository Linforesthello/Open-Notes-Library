> # 🟢 一、最实用（必须掌握）：命令行工具
> 
> 这一层你**一定要会**，因为：
> 
> 👉 快  
> 👉 不占内存  
> 👉 适合超大 CSV（日志文件）
> 
> ---
> 
> ## 1️⃣ `awk`（最强文本处理）
> 
> ### 🔥 按行截取
> 
> ```bash
> awk 'NR>=100 && NR<=200' data.csv > out.csv
> ```
> 
> ### 🔥 按条件筛选（比如 CAN ID）
> 
> ```bash
> awk -F',' '$2==123' data.csv > out.csv
> ```
> 
> 👉 解释：
> 
> - `NR` = 行号
>     
> - `-F','` = CSV 分隔符
>     
> 
> ---
> 
> ## 2️⃣ `head / tail`（简单粗暴）
> 
> ```bash
> head -n 100 data.csv        # 前100行
> tail -n 100 data.csv        # 后100行
> tail -n +50 data.csv        # 从第50行开始
> ```
> 
> 👉 优点：
> 
> - 极快（C语言实现）
>     
> - 几GB文件也秒开
>     
> 
> ---
> 
> ## 3️⃣ `sed`（范围截取）
> 
> ```bash
> sed -n '100,200p' data.csv > out.csv
> ```
> 
> 👉 和 awk 类似，但更偏“范围操作”
> 
> ---
> 
> ## 📌 这一层总结
> 
> |工具|推荐指数|场景|
> |---|---|---|
> |awk|⭐⭐⭐⭐⭐|过滤 + 处理|
> |head/tail|⭐⭐⭐⭐|快速截取|
> |sed|⭐⭐⭐|简单范围|
> 
> 👉 **结论：**
> 
> > 日志分析 = awk 是王
> 
> ---
> 
> # 🟡 二、CSV专用工具（更优雅）
> 
> ## 4️⃣ csvkit（强烈推荐）
> 
> 👉 Python生态，但命令行风格
> 
> 安装：
> 
> ```bash
> pip install csvkit
> ```
> 
> ---
> 
> ### 🔥 查看CSV结构
> 
> ```bash
> csvstat data.csv
> ```
> 
> ---
> 
> ### 🔥 选列
> 
> ```bash
> csvcut -c 1,3 data.csv
> ```
> 
> ---
> 
> ### 🔥 筛选
> 
> ```bash
> csvgrep -c 2 -m 123 data.csv
> ```
> 
> ---
> 
> 👉 优点：
> 
> - 比 awk 更“懂 CSV”
>     
> - 不怕逗号/引号问题
>     
> 
> ---
> 
> ## 📌 对比 awk
> 
> |特性|awk|csvkit|
> |---|---|---|
> |性能|⭐⭐⭐⭐⭐|⭐⭐⭐|
> |CSV规范支持|❌|✅|
> |易用性|一般|高|
> 
> 👉 结论：
> 
> > 小心格式 → 用 csvkit  
> > 极致性能 → 用 awk
