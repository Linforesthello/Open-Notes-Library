> 
> ---
> 
> ## v1.2目标
> 
> 增加：
> 
> ### 1. CSV导出（Excel可打开）
> 
> 生成：
> 
> ```
> B站收藏夹.csv
> ```
> 
> 格式：
> 
> |标题|BV号|播放量|弹幕|时长|链接|
> |---|---|---|---|---|---|
> |斯坦福CS221...|BV1K7411T7bB|4643|33|13:34:33|https://...|
> |机器人控制中的优化...|BV1PE6CBhEcZ|2128|1|38:29:02|https://...|
> 
> 优点：
> 
> - Excel排序
>     
> - 搜索关键词
>     
> - 筛选课程
>     
> - 后续建立知识库
>     
> 
> ---
> 
> ### 2. 增加“复制链接模式”
> 
> 现在复制：
> 
> ```
> 标题
> 
> BV号
> 
> 播放量
> 
> ...
> ```
> 
> 适合保存。
> 
> 但是转发给别人不方便。
> 
> 增加两个按钮：
> 
> ```
> 复制详细
> 复制纯链接
> ```
> 
> 纯链接：
> 
> ```
> https://www.bilibili.com/video/BV1K7411T7bB
> https://www.bilibili.com/video/BV1PE6CBhEcZ
> ```
> 
> 适合：
> 
> - 群聊
>     
> - 邮件
>     
> - 文档引用
>     
> 
> ---
> 
> ### 3. 增加收藏夹名称
> 
> 你的地址：
> 
> ```
> favlist?fid=3650644310&ftype=create
> ```
> 
> 其实有收藏夹名字。
> 
> 例如：
> 
> ```
> 机器人学习
> ```
> 
> 导出增加：
> 
> ```
> 收藏夹：
> 机器人学习
> ```
> 
> 方便以后多个收藏夹合并。
> 
> ---
> 
> ### 4. 保存 JSON
> 
> 增加：
> 
> ```
> B站收藏夹.json
> ```
> 
> 例如：
> 
> ```json
> [
>  {
>   "title":"斯坦福CS221",
>   "bvid":"BV1K7411T7bB",
>   "views":"4643",
>   "danmu":"33",
>   "duration":"13:34:33",
>   "url":"https://..."
>  }
> ]
> ```
> 
> 以后可以：
> 
> - Python处理
>     
> - 导入数据库
>     
> - 自动生成笔记
>     
>

> ## 另外建议加入一个重要功能
> 
> ### 自动保存缓存
> 
> 现在有一个隐患：
> 
> 你扫描：
> 
> 第一页：
> 
> ```
> 100个
> ```
> 
> 然后刷新网页：
> 
> 全部消失。
> 
> v1.2加入：
> 
> ```javascript
> localStorage
> ```
> 
> 自动保存：
> 
> 浏览器关闭也存在。
> 
> 例如：
> 
> 今天：
> 
> ```
> 机器人收藏夹
> 300条
> ```
> 
> 明天继续：
> 
> ```
> +50条
> ```
> 
> 最后：
> 
> ```
> 350条
> ```
>
