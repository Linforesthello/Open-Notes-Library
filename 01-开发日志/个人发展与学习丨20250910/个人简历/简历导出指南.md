# 简历导出指南（Markdown PDF 插件）

> 2026-08-23 留档 · 适用范围：`个人简历/` 目录下所有简历 md → PDF
> 相关文件：[resume.css](resume.css)（排版样式）｜[信息池_简历作品集素材.md](信息池_简历作品集素材.md)（素材源）

## 1. 生成流程（入口）

1. VSCode 打开简历 md（如 `李泽林_机器人运动控制工程师_20260823.md`）
2. 命令面板 `Ctrl+Shift+P` → **Markdown PDF: Export (settings.json)**
3. 同目录生成同名 `.pdf`（覆盖旧文件）

**链路**：md → 插件模板（template.html）+ 默认样式（markdown.css）+ 自定义样式（resume.css）→ HTML → Chromium printToPDF → PDF

## 2. 配置位置（⚠️ 最重要）

**当前生效配置不在默认用户设置里，而在 profile「主力-嵌软」：**

| 层 | 位置 | 状态 |
|:---|:---|:---|
| 默认用户设置 | `~/.config/Code/User/settings.json` | markdown-pdf 段已注释，**不生效** |
| **生效（profile 主力-嵌软）** | `~/.config/Code/User/profiles/532aae18/settings.json` | ✅ 实际生效（GUI 修改写入位置） |

> ⚠️ GUI（设置 → 扩展 → Markdown PDF）的修改会写入**当前激活的 profile**。以后调参先确认当前 profile 是「主力-嵌软」，否则会出现"改了没反应"。

**当前生效配置清单**（`profiles/532aae18/settings.json`）：

```json
"markdown-pdf.styles": ["/home/lin/Lin_note/Open-Notes-Library/01-开发日志/个人发展与学习丨20250910/个人简历/resume.css"],
"markdown-pdf.margin.top": "10mm",
"markdown-pdf.margin.bottom": "10mm",
"markdown-pdf.margin.left": "10mm",
"markdown-pdf.margin.right": "10mm",
"markdown-pdf.headerTemplate": "",
"markdown-pdf.footerTemplate": "",
"markdown-pdf.displayHeaderFooter": false,
"markdown-pdf.chromium.autoDownload": false
```

（mermaidServer 未设 → 用默认 unpkg CDN；简历无 mermaid 图不会卡，见 §4.1）

## 3. 可调参数

### 3.1 页面级（GUI：设置 → 扩展 → Markdown PDF）

| 参数 | 当前值 | 说明 |
|:---|:---|:---|
| Display Header Footer | 关 | 页眉页脚开关（文件名+日期页眉就是它） |
| Header / Footer Template | 空 | 自定义页眉页脚 HTML |
| Margin: Top/Bottom/Left/Right | 10mm | 纸张边距，紧凑可调小（≥6mm） |
| styles | [resume.css] | 自定义样式表列表 |
| Format | A4 | 纸张规格 |
| Mermaid Server | 默认 CDN | 见 §4.1 |

### 3.2 排版级（resume.css）

| 参数 | 当前值 | 调小 → 更紧凑 |
|:---|:---|:---|
| body font-size | 10pt | 9.5pt |
| body line-height | 1.45 | 1.35 |
| body padding | 0 | ⚠️ 必须为 0（防与页面 margin 叠加，见 §4.3） |
| p / ul / ol margin | 2px / 2px→6px | 1px |
| li margin | 1.5px | 1px |
| h1 / h2 / h3 | 18pt / 11.5pt / 10.5pt | — |

**调参顺序**：先 css（字号 → 行距 → 间距）→ 再页面 margin → 重新导出即生效（无需重启/重载）。

## 4. 踩坑记录

1. **导出卡住**：插件模板无条件加载 unpkg mermaid CDN 且等待 `networkidle0`，网络不可达会挂起。简历无 mermaid 图则不受影响；若再卡：把 Mermaid Server 指向本地 `file:///home/lin/.local/share/markdown-pdf/mermaid.min.js`（npmmirror 下载的离线版）
2. **页眉删不掉**：键名是**驼峰** `displayHeaderFooter`（不是 display-header-footer），默认 true；GUI 取消勾选最稳
3. **边距异常大**：插件默认 markdown.css 有 `body { padding: 0 26px }` 与页面 margin 叠加 → resume.css 里 `padding: 0` 覆盖
4. **配置改了没反应**：① 配置段在 settings.json 里被注释（GUI 显示默认值）② GUI 修改写进的是**当前 profile**，不是默认用户设置（见 §2）
5. **JSON 语法合法 ≠ schema 合规**：手改 settings.json 曾把 `workbench.settings.applyToAllProfiles` 写成 `{}`（应为 `string[]`）导致 VSCode 黑屏——不确定类型时先查官方 schema/文档，或干脆走 GUI
