## 项目经历

### 1. R2 全向轮底盘 · ROS2 自主导航系统（2026.07 – 至今）｜ 运动控制链路负责人

主导从 STM32 电机固件到 ROS2 导航的完整控制链路，端到端打通"指令→执行→反馈"闭环，全链路实车验证通过。

- **底盘运动学与控制**：完成四全向轮正/逆运动学建模（vx/vy/ω 三自由度、90° 辊子构型），建立 /cmd_vel → CAN → 电机闭环映射；基于 8 组方向标定实验与编码器 ticks/圈实测校准参数，方形闭环轨迹误差由 1.8m 降至 0.27m
- **CAN 通信协议设计**：设计 8 字节命令/状态帧协议（命令 ID 0x123~0x126，状态 ID 0x323~0x326，50ms 主动上报），实现四电机分布式控制与实时状态监测（转速/PWM/堵转标志）
- **电机闭环（固件层）**：MCLM 固件 PID 100Hz 闭环，堵转保护与饱和检测机制
- **EKF 多传感器融合**：robot_localization 融合 G354 IMU（100Hz，Mahony 互补滤波）与轮速里程计；调试 225 值过程噪声矩阵与协方差病态问题；修复 z 轴漂移 85m → 亚米级（two_d_mode 钳位）与 yaw 偏差 179° → 0.07°（含 90°/190° 转弯实测）
- **IMU 驱动与轴标定**：G354 串口驱动开发，修复出厂轴定义与车体坐标系不一致问题
- **端到端集成与排障**：VLP-16 + AMCL + MPPI 实车导航闭环（降额参数全程无碰撞）；定位 CPU 治理器为建图帧率根因（3.6→9.5Hz）、VLP-16 供电不足链路降速、跨机 DDS 发现失败；完成 FAST-LIO2 在 VLP-16 平台的部署验证
- **机械臂执行链路（衔接）**：R2 机械臂（RS00 + M8010-6）关节电机控制独立成项见项目 2——与底盘共享 CAN/部署环境，构成 R2 移动操作平台完整执行层

### 2. R2 机械臂 · 关节电机执行链路（2026.05 – 至今）｜ 控制软件

R2 移动操作平台的机械臂执行链路（真机侧），与 RL 策略训练形成"仿真训练 + 真机执行"闭环。

- **RS00 准直驱关节电机**：肩/肘双关节（14N·m 峰值、10:1 减速比）PC 端 CAN 控制，Python socketCAN（CANable2，1Mbps 29-bit 扩展帧）；运控/CSP 双模式，CSP 位置闭环免调参、到位误差 ≤0.1°（实测）（0.3~3.0 rad/s 运行时调速）
- **CAN 指令封装与安全机制**：8 类底层指令（Type 1/3/4/6/7/17/18/24）封装为控制类；硬件标零（flash 一次写入）与关节限位保护（肩 -85°~+85°、肘 -70°~+110°）
- **宇树 GO-M8010-6 关节电机**：C++ USB 转 RS485（4Mbps）FOC 控制，缓变位置闭环（固定步长逼近，避免力矩冲击）+ 速度/停止模式；修复减速比重复计算（-40.07→-6.33）、转子磁编码器反向补偿、SIGINT 信号处理死锁（Ctrl+C 自动安全停机）
- **状态监控**：被动监听监控器实时监视双电机状态，不干扰控制时序
- **跨平台部署**：控制代码 PC 开发 → N97（Linux）部署成功；M8010-6 另部署树莓派 4B 验证，体现代码可移植性与 Linux 环境适配能力
