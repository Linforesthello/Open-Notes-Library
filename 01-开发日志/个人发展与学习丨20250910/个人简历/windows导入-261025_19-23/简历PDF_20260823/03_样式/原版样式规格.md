# 原版样式规格（从 `01_原件参考\resume.css` 逐条提取）

> 结论：这份规格就是"你觉得好看"的那套。以下数字**照搬**，不做任何重设计。

## 一、原版全部生效值

| 元素 | 原版值 |
|:--|:--|
| `body` | `font-size: 10pt` / `line-height: 1.45` / `color: #222` / `padding: 0` / 字体族 Noto Sans CJK SC → Microsoft YaHei → WenQuanYi Micro Hei |
| `h1`（姓名） | `18pt` / `margin: 0 0 4px 0` / `text-align: center` |
| `h2`（区块标题） | `11.5pt` / `border-bottom: 1px solid #333` / `padding-bottom: 2px` / `margin: 10px 0 4px 0` |
| `h3`（项目标题） | `10.5pt` / `margin: 8px 0 2px 0` |
| `p` | `margin: 2px 0` |
| `ul` / `ol` | `margin: 2px 0 6px 0` / `padding-left: 16px` |
| `li` | `margin: 1.5px 0` |
| `hr` | `border-top: 1px solid #ddd` / `margin: 8px 0` |
| `a` | `color: #1a5fb4` / 无下划线 |
| `strong` | `color: #111`（**不设字重**） |
| `blockquote` | 左边框 3px `#ccc` / `margin: 8px 0` / `padding: 2px 10px` / `color: #666` / `font-size: 9pt` |

### 两个容易忽略的关键点

1. **标题是细体，不是粗体**：原版没有设 `font-weight`，而插件默认样式里有 `h1,h2,h3 { font-weight: normal }`——所以原版标题呈**细体**。我上一版擅自加了 `700`，看起来"加粗了"，就是从这里来的。
2. **整篇左对齐**：原版没有 `text-align: justify`。我上一版加了两端对齐，也属于擅自改动。

## 二、我相对原版只加了 3 处（其余逐属性照抄）

| 新增 | 为什么加 |
|:--|:--|
| `h2 + ul li { white-space: nowrap }` | 单页版的「核心能力」是 5 行关键词索引，不折行才是一行一族 |
| `h2/h3 { break-after: avoid }` | 防止标题孤零零落在页尾 |
| `li { break-inside: avoid }` | 防止单条被分页切断 |

## 三、这套规格的直接后果：**大概率 2 页**

原版 `resume.css` 是为**网申版**（内容 7.5KB、两页）设计的。单页文字版虽然内容更少，但 10pt / 1.45 的行距下，正文高度我粗算约 **269mm**，A4 去 10mm 边距可用 **277mm**——卡在门口，差一点就翻页。

- 若实测 1 页：理想，直接用
- 若实测 2 页：优先**减内容**（合并/删修饰句），其次按微调区第 1 组温和收（`line-height 1.45→1.40`、`li 1.5→1.2px`），**不要**再整体重设计字号

## 四、目录隔离（保证"只动规划控制"）

```
02_简历正文\
├── resume.css                              ← 根目录副本（网申版/重排版/运控单页 共用）
├── 李泽林_运控_单页文字版.md
└── 规划控制_单页\
    ├── resume.css                          ← 规划控制专用，今后只改这里
    └── 李泽林_规划控制_单页文字版.md
```

原理：`stylesRelativePathFile: true` 让 `styles: ["resume.css"]` **相对 md 所在目录**解析。
所以导出 `规划控制_单页\` 里的 md 时，用的就是同目录那份 `resume.css`——**不受根目录影响，也不会影响根目录**。配置无需再改。
