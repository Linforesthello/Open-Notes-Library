# 简历 PDF 首次使用指南

> 面向：第一次用这套流程的人（或几个月后的自己）
> 适用：把 `.md` 简历用 VS Code `Markdown PDF` 插件导出成 A4 美观 PDF
> 预计耗时：首次 15 分钟（含配置），之后每次导出 30 秒
> 背景与踩坑记录见 [00_全流程留档.md](00_全流程留档.md)

---

## 0. 一句话原理

插件把 `.md` 转成 HTML，再套上 **你指定的 CSS** 交给 Chromium 打印成 PDF。
**只要 CSS 真的被加载，观感就由你说了算**；而"CSS 没加载"这件事插件**不会报错**——这是本流程唯一的真坑，下面第 3 步专门防它。

---

## 1. 前置检查（2 分钟）

| 检查 | 怎么做 | 通过标准 |
|:--|:--|:--|
| 插件已装 | 扩展面板搜 `Markdown PDF`（作者 yzane） | 已启用，版本 2.2.x |
| 当前 profile | `Ctrl+Shift+P` → `Profiles: Switch Profile` | 记住你用的是哪个（本机是「主力-嵌软」= `532aae18`） |
| 中文字体 | 资源管理器打开 `C:\Windows\Fonts` | 有 `NotoSansSC-VF.ttf`（族名 **Noto Sans SC**）；没有也能跑，会回退微软雅黑 |

> **字体名陷阱**：CSS 里写 `'Noto Sans CJK SC'` 在 Windows 上**不存在**（中文名带 CJK 的是 Linux 版），本机装的是 `'Noto Sans SC'`。差一个词，就会静默回退到雅黑，观感完全不同。

---

## 2. 摆文件（一版一目录）

新建一个目录，**md 和 resume.css 必须放在同一层**：

```
我的简历\
├── 李泽林_XXX.md        ← 简历正文
└── resume.css           ← 该版专用样式（从 03_样式\ 复制一份过来改）
```

为什么必须同目录：下一步会开启"相对路径解析"，插件会到这个 md 的**同目录**找 `resume.css`。这样一版一套样式，互不串味，Linux/Windows 通用。

---

## 3. 配置（只做一次，3 步）

### 3.1 打开正确的配置文件

`Ctrl+Shift+P` → 输入 `Preferences: Open User Settings (JSON)` → 回车。

⚠️ **看标签页路径**，结尾必须是：

```
...\Code\User\profiles\<你的profile>\settings.json
```

如果结尾只有 `...\Code\User\settings.json`（没有 `profiles` 那层），说明改错文件了——那一份在本机是被注释掉的，改了不生效。

### 3.2 写入/替换这两行

```json
"markdown-pdf.stylesRelativePathFile": true,
"markdown-pdf.styles": ["resume.css"],
```

保留同段里这些既有键（本机已配好，别删）：

```json
"markdown-pdf.format": "A4",
"markdown-pdf.margin.top": "10mm",
"markdown-pdf.margin.bottom": "10mm",
"markdown-pdf.margin.left": "10mm",
"markdown-pdf.margin.right": "10mm",
"markdown-pdf.displayHeaderFooter": false,
"markdown-pdf.printBackground": true
```

**只用 GUI 改也行**：`Ctrl+,` → 搜索 `@ext:yzane.markdown-pdf` → 找到 **Styles**（删掉旧条目、添加 `resume.css`）→ 再搜 `stylesRelativePathFile` 勾上。GUI 改完自动保存。

### 3.3 重载窗口

`Ctrl+Shift+P` → `Developer: Reload Window`。

> 插件在激活时读配置，不重载可能仍用旧值。

---

## 4. 导出（30 秒）

1. 在 VS Code 打开那版 `.md`
2. `Ctrl+Shift+P` → `Markdown PDF: Export (pdf)`
3. 同目录出现同名 `.pdf`

> `Export (pdf)` 与 `Export (settings.json)` 导 PDF **完全等价**，只差"是否按 `markdown-pdf.type` 决定格式"。用哪个都行。

---

## 5. 验证（4 个判据，1 分钟）

按可靠性从高到低：

| # | 判据 | 通过标准 | 不过说明 |
|:--:|:--|:--|:--|
| 1 | 姓名排版 | 字号明显大于正文（18pt vs 10pt） | 完全一样大 → CSS 没加载 |
| 2 | 姓名下方有无横线 | 无 | 有 → 用的是插件默认样式（默认会给 h1 加下划线） |
| 3 | 技能特长类别标签 | 每条以 `导航与 SLAM：`、`状态估计：` 等开头且完整 | 标签消失 → 命中"悬挂缩进裁标签"坑（见第 9 节） |
| 4 | 页数 | 与预期一致（单页版 1 页 / 网申版 2 页） | 多出来 → 内容超了，按第 8 节微调 |

想更严谨（可选）：用 `_分析\pdf_layout.py` 解析字体与字号：

```powershell
$py = 'C:\Users\86173\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'
& $py _分析\pdf_layout.py "你的.pdf" 本次导出
```

正常应看到：`页数 1` / `BaseFont 含 NotoSansSC` / `字号 13.33、14.0、15.33、24.0` / `行基线间距 21.00`。

## 6. 失败对照表

| 现象 | 大概率原因 | 处理 |
|:--|:--|:--|
| 改了 CSS 毫无变化 | styles 路径不对（插件静默跳过） | 检查 `stylesRelativePathFile: true` 和 `styles: ["resume.css"]`；确认 md 与 css 同目录 |
| 设置界面改了没生效 | 改的是用户级 settings（那份是注释掉的），或 profile 没切对 | 按 3.1 确认配置文件路径 |
| 页面上下多出文件名/日期/页码 | `displayHeaderFooter` 被重置为 true | 设回 `false` |
| 左右留白特别大 | 默认样式 `body{padding:0 26px}` 叠加 | 样式里写 `padding: 0` |
| 字体看着"更壮" | 回退到了微软雅黑 | 字体栈首位放 `'Noto Sans SC'` |
| 加粗偏重 | 原版用合成粗，本机命中真 Bold | `strong { font-weight: 600; }` |
| 导出卡住 | 插件等 mermaid CDN | 简历无 mermaid 图一般不受影响；卡住再查网络 |
| 技能特长标签消失 | 用了 `text-indent` 悬挂缩进 | 见第 9 节，删掉那两条规则 |

## 7. 三套样式怎么配（一个样式配一套结构）

| 样式文件 | 配哪份 md | 结构特征 |
|:--|:--|:--|
| `resume-正式-单页版.css` | 单页文字版 | 核心能力 5 行索引 + 段落式项目 + 技能特长 6 段，1 页 |
| `resume-正式-重排版.css` | 重排版 | 同上但内容更长（约 5,800 字），2 页 |
| `resume-正式-网申版.css` | 网申版 | 教育背景前置、技能特长在末尾，2 页 |

**切换版式** = 把 `03_样式\` 里对应文件覆盖到目标目录的 `resume.css`，然后重新导出。配置不用动。

## 8. 微调速查

| 想要 | 改哪 | 怎么改 |
|:--|:--|:--|
| 内容超页、要更紧 | body | `font-size: 9.8pt; line-height: 1.4;` |
| 还超 | p / li | `p { margin: 1.5px 0 }`、`li { margin: 1px 0 }` |
| 页面太空、想舒展 | body | `font-size: 10.5pt; line-height: 1.5;` |
| 姓名想居中 | h1 | `text-align: center;` |
| 核心能力想恢复圆点 | `h2 + ul` | `list-style: disc; padding-left: 16px;` |
| 核心能力想更紧 | `h2 + ul li` | `line-height: 1.25; margin: 0.1px 0;` |
| 分隔符想从 `·` 换回 `｜` | md | 改 5 行（只动 `- ` 开头的行） |
| 去掉标题横线 | h2 | `border-bottom: none;` |

**优先动内容，其次动 CSS**：压字号/行距最容易把"你喜欢的观感"改掉。

---

## 9. 四条禁止事项（都是踩过的坑）

| 禁止 | 为什么 |
|:--|:--|
| ❌ 用 `padding-left + text-indent + inline-block` 做悬挂缩进 | 会把 inline-block 标签推到页面外整段裁掉（实测 6 个标签全消失、少 33 字符）。要真对齐请把 md 改成列表或两列表格 |
| ❌ 在 styles 里写绝对路径（尤其 Linux 路径） | 换机器就失效，且插件**静默跳过**，表现为"改什么都没用" |
| ❌ 用 `!important` 硬拼默认样式 | 用户样式注入在默认样式之后，标签级覆盖足够；`!important` 会掩盖真正问题 |
| ❌ 改动 `04_对照基准\` 里的任何文件 | 那是 A/B 参照物，改了就没有基准可比 |

---

## 10. 新增一份简历的 checklist

```
□ 1. 新建目录：“<版本名>\”
□ 2. 放入 md + 从 03_样式\ 复制一份合适结构的 resume.css
□ 3. 检查 styles 配置仍是 stylesRelativePathFile:true / ["resume.css"]
□ 4. Reload Window（改过配置才需要）
□ 5. 打开 md → Export (pdf)
□ 6. 验证四判据：姓名字号 / 姓名下横线 / 技能标签齐全 / 页数
□ 7. 需要精查时跑 _分析\pdf_layout.py
□ 8. 把本次改动记进 00_全流程留档.md（版本、原因、效果）
```

## 11. 现行样式快照（v2.1 单页版，可直接照抄）

```css
body {
  font-family: 'Noto Sans SC', 'Noto Sans CJK SC', 'Droid Sans Fallback', 'Microsoft YaHei', sans-serif;
  font-size: 10pt;
  line-height: 1.45;
  color: #222;
  padding: 0;
}
h1 { font-size: 18pt; margin: 0 0 2px 0; text-align: left; letter-spacing: 0.5px; }
h2 { font-size: 11.5pt; border-bottom: 1px solid #333; padding-bottom: 2px; margin: 10px 0 4px 0; }
h3 { font-size: 10.5pt; margin: 8px 0 2px 0; }
p  { margin: 2px 0; }
ul { margin: 2px 0 6px 0; padding-left: 16px; }
li { margin: 1.5px 0; }

/* 核心能力索引块 */
h2 + ul { list-style: none; padding-left: 0; margin: 1px 0 4px 0; }
h2 + ul li { white-space: nowrap; line-height: 1.35; margin: 0.3px 0; }

/* 技能特长：仅去换行（不要用 text-indent） */
p > strong:first-child { white-space: nowrap; }
```

> 注：`ul` 有两条规则，后者只命中"紧跟 h2 的那个列表"（本结构里就是核心能力）。如果将来给某个区块也改成 `## 标题 + 列表`，这条会误命中——届时改用 `h2:first-of-type + ul` 收窄范围。
