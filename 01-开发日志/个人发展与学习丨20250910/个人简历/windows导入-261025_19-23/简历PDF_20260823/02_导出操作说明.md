# 导出操作说明（单页版 · 打通链路）

> 目标：先只跑通**一份**简历的导出，确认样式真的被加载，再批量做其余版式。
> 当前已就位：`02_简历正文\resume.css`（单页版正式样式）+ 6 份 md。

---

## 一、要改的配置（只改 2 行）

打开 `C:\Users\86173\AppData\Roaming\Code\User\profiles\532aae18\settings.json`，
找到原来的：

```json
"markdown-pdf.styles": [
    "/home/lin/Lin_note/Open-Notes-Library/01-开发日志/个人发展与学习丨20250910/个人简历/resume.css"
],
```

**替换为**：

```json
"markdown-pdf.stylesRelativePathFile": true,
"markdown-pdf.styles": ["resume.css"],
```

其余键（`margin.*` = 10mm、`displayHeaderFooter` = false、`format` = A4、`headerTemplate`/`footerTemplate` = ""）**保持不动**，它们本来就配对了。

> 原理：`stylesRelativePathFile: true` 让 `"resume.css"` 相对 **md 文件所在目录**解析。
> 于是 `02_简历正文\resume.css` 会被自动加载，且**在 Linux 上同样成立**，不再出现"路径失效但静默跳过"。

### 如果相对路径不生效（备选方案）

改用绝对路径（正斜杠写法最省事）：

```json
"markdown-pdf.styles": [
    "C:/Users/86173/Documents/deepseek-harness/default-workspace/简历PDF_20260823/02_简历正文/resume.css"
],
```

## 二、操作步骤

1. **确认 profile**：VS Code 左下角显示的 profile 必须是 `532aae18` 对应的那个（"主力-嵌软"）。
   用 `Ctrl+Shift+P → Profiles: Switch Profile` 核对。
2. 按第一节**替换配置**，保存。
3. `Ctrl+Shift+P → Developer: Reload Window`（插件不一定热读配置，必须重载）。
4. 打开 `02_简历正文\李泽林_运控_单页文字版.md`。
5. `Ctrl+Shift+P → Markdown PDF: Export (settings.json)`。
6. 同目录生成 `李泽林_运控_单页文字版.pdf`。

| # | 判据 | 说明 |

| 1 | **姓名"李泽林"是否居中** | 只有用户 CSS 设了 `text-align:center`；默认样式是左对齐。**这条不过 = 样式没加载**，先回去查路径/profile，别调 CSS |
