## 四、样式要点（两套一致，改内容时勿动）

- 字体 `Noto Sans SC` 优先（与原版 Linux 的 Droid 同源）
- 姓名：18pt、左对齐、下边距 2px、无下划线
- `h2`：11.5pt + `1px solid #333` + `10px 0 4px`
- `h3`：10.5pt + `8px 0 2px`
- `p` 2px / `li` 1.5px / `ul` 16px 缩进
- 核心能力：`h2:first-of-type + ul` 命中（去圆点 / nowrap / line-height 1.35）
- **技能特长不命中**该规则：A 版是段落形态、B 版是列表（保留 9 条圆点 + 正常换行）
- 禁用：`padding-left + text-indent` 悬挂缩进（会裁掉标签，实测少 33 字符）

## 五、内容阶段的工作约定

1. **改的是 `02_简历正文\规划控制_单页\` 与 `02_简历正文\规划控制_重排版\` 里的 md**，不是本目录
2. 本目录**只读**；每次改完重新导出，与本目录的 PDF 对比
3. 页数变化属于内容成效（B 版删少量内容即可 3 页 → 2 页）
4. 若观感出现非预期变化（字体/字号/间距/圆点消失），说明误改了 `resume.css`，从本目录回滚
5. 两版内容要**同步演进**：同一事实的口径（yaw、0.27m、97.75%、12 节点）必须两边一致
