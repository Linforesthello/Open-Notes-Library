### 1. R2 全向轮底盘 · ROS2 自主导航系统（2026.07 – 至今）｜ 运动控制链路负责人

主导从 STM32 电机固件到 ROS2 导航的完整控制链路，端到端打通"指令→执行→反馈"闭环，全链路实车验证通过。

**负责范围**：建图与定位链路（VLP-16/AMCL/MPPI）、底盘运动学与 CAN 协议、电机闭环固件、IMU 驱动与 EKF 融合、机械臂关节电机控制、系统级排障——除硬件与机械结构由队友负责外，以上环节均由本人独立完成；机械臂关节控制另成项目 2。

- **底盘运动学与控制**：完成四全向轮正/逆运动学建模（vx/vy/ω 三自由度、90° 辊子构型），建立 /cmd_vel → CAN → 电机闭环映射；CAN ID→物理位置映射程序化确认（map_chassis.py）+ 8 组方向标定（calibrate_direction.py）与编码器 ticks/圈实测（均值 4241），配套 0.5s 无指令自动停止的超时保护；方形闭环位移差由 1.8m 降至 0.27m（终点位置漂移口径，KISS 交叉验证 0.24m）
- **CAN 通信协议设计**：设计 8 字节命令/状态帧协议（命令 ID 0x123~0x126，状态 ID 0x323~0x326，50ms 主动上报），实现四电机分布式控制与实时状态监测（转速/PWM/堵转标志）
- **电机闭环（固件层）**：MCLM 固件 PID 100Hz 闭环，堵转保护与饱和检测机制
- **EKF 多传感器融合**：robot_localization 融合 G354 IMU（100Hz，Mahony 互补滤波）与轮速里程计；调试 225 值过程噪声矩阵与协方差病态问题；修复 z 轴漂移 85m → 亚米级（two_d_mode 钳位，slip 场景 +2.5m 待跟进）；修正轮速 yaw 与 IMU 最大偏差 179° → 7~20°、转弯测试 yaw 偏差 179° → 4~14°（KISS 交叉验证一致），EKF yaw 方案①精细化后达 0.07°（以上均为实车实测口径）
- **IMU 驱动与轴标定**：G354 串口驱动（38 字节轮询 + Mahony 姿态解算 Kp=1.0/Ki=0.005 + ZUPT）；修复出厂轴定义与车体坐标系不一致（mount_axes + 初始化/Mahony 两处符号）；静置测试 yaw 漂移 0.002°/min（132s 仅漂 0.005°）
- **端到端集成验证**：VLP-16 + AMCL + MPPI 实车导航闭环（降额参数全程无碰撞），打通"定位→规划→执行"整链
- **底盘里程计修复（根因级）**：定位 omega 单位多除轮半径导致放大 13.2× + 全向轮积分问题，bag 前后对比使 yaw 偏差 179° → 4~14°、方形闭环位移差 1.80m → 0.27m
- **系统级排障**：定位 CPU 治理器为建图帧率根因（3.6→9.5Hz）、VLP-16 供电不足链路降速、跨机 DDS 发现失败（FastDDS 固定端口 7410 + 单播 Peer 绕开 VMware NAT 组播不通）、IMU 协方差病态致 EKF NaN（非对角项填满致矩阵奇异→对角化）；完成 FAST-LIO2（LiDAR-IMU 紧耦合）在 VLP-16 平台的部署与实车验证（旋转 <2°：左转 91.9°/+1.9°、右转 −89.4°/+0.6°，z 全程 ±4cm；平移 <1%：尺子 169cm → 2D/3D 169.86/169.98cm）
- **系统运行基线（N97 实机）**：12 节点全套（IMU 100Hz / EKF /odometry/filtered 30Hz / 轮速 50Hz / 点云 9.3~9.4Hz / KISS-ICP 9.5Hz）；定位 CPU 为单机性能瓶颈并据此约束功能扩展
- **低矮障碍盲区专项（costmap 机理，08-25~09-08）**：按 VLP-16 向下 ring 几何律标定盲区边界（−15° ring 打顶 1.59m，逐帧实测≈1.6m，偏差 <1cm）；实车撞箱坐实根因——局部 costmap 有 254 低障碍而全局 costmap 无低带源，planner 用全局图规划生成直冲路线、全程无避让；修复 = 独立 obstacle_low_layer（mark-only / clearing 关闭），VM 双录重放 A/B 验收 PASS、实车首次接近停障有效；进一步定位二次失效根因（新 goal 触发 global 整层清空、抹掉保留 mark、盲区不可再生）

- **状态监控**：被动监听监控器实时监视双电机状态，不干扰控制时序
- **跨平台部署**：控制代码 PC 开发 → N97（Linux）部署成功；M8010-6 另部署树莓派 4B 验证，体现代码可移植性与 Linux 环境适配能力
