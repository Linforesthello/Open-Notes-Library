## 二、补写清单（按落点粒度，可直接执行）

### 1. 【A 版·最优先】补"双 CAN 分布式网络"——运控版的项目 4 缺了最硬的一条

- 现状：A 版 Robocon 段（L59–63）**没有** B3。而运控岗最想看的恰是"多节点实时总线 + 故障检测"。
- 改法：在 L60（FreeRTOS 条）之后插入一条：
  > `- **双 CAN 分布式网络**：STM32F407 主控 + 4×STM32F446 舵轮模块协同，心跳包/看门狗/故障检测机制，电机转速/电流/温度实时监测`
- 依据：池 B3；源出处"简历 06-03 版"（注意：该出处文件不在当前 3 份文件内，回查链断，见三-3）。

### 2. 【两版·高优先】把 A11 + A13 合并成一条"系统级工程能力"

- 现状：性能基线（IMU 100Hz / EKF 30Hz / 轮速 50Hz / 点云 9.3~9.4Hz / KISS 9.5Hz）与 12 节点组成**两版都没写**。
- 改法：运控版插在 L34"系统级排障"后；规划版并入 L35 尾部：
  > `- **系统运行基线（N97 实机）**：12 节点全套（IMU 100Hz / EKF 30Hz / 轮速 50Hz / 点云 9.3~9.4Hz / KISS-ICP 9.5Hz），定位 CPU 为单机性能瓶颈并据此约束功能扩展`
- 价值：把"我跑通过"升级为"我知道系统的极限在哪"——这是面试里区分"调包"和"工程"的分水岭。

### 3. 【B 版·高优先】A19 选型对比只用了 2/6，补齐可量化项

- 现状：B 版 L37 只写了 KISS-ICP vs FAST-LIO2、VLP-16 vs MID-70。池 A19 里**还有**：SLAM Toolbox（ATE 0.13m）vs Cartographer（0.21m）、MPPI vs TEB（Humble 弃养）、AMCL → FAST-LIO-Localization。
- 改法：L37 扩成一条三点式：
  > `- **选型对比与量化**：①建图 KISS-ICP（旋转漂移实测 163°）→ FAST-LIO2 接 G354 解决；②2D SLAM Toolbox（ATE 0.13m）vs Cartographer（0.21m）；③传感器 VLP-16（360°/16 线稀疏）vs MID-70（70° 均匀密点/Livox 原生）实车 A/B 定夺；局部控制选 Nav2 官方 MPPI（TEB 在 Humble 已弃养）`
- 注意：②的两个 ATE 数字必须能说清测量条件，否则会成为面试自爆点。

### 4. 【两版·中优先】A20/A21 文档纪律加"数字锚点"

- 现状：两版都只有一句"文档规范体系（单一事实来源 / 维护契约 / 调研选型附来源可回查）"。规范本身没有"量"。
- 改法：改为带数字的表述：
  > `- **工程素养**：`模块|主题` git 提交规范（改动/原因/影响三段）；11 条文档规范（单一事实来源 / 维护契约 / 调研选型附来源）；40+ 篇排障复盘（踩坑必有结论）；2026-08-23 完成 roadmap 全篇真实性回溯（8 处补来源 + 2 处存疑不编造）`
- 价值：最后半句"存疑不编造"比任何自我评价都更能证明可信度。

### 5. 【两版·中优先】A10 / A14 / A15 挑 1–2 个数字进 B 版（地图与可复现性）

- 现状：B 版 L28 只说"开发人形块过滤工具产出清洗版场地地图"，量化全丢。
- 改法：L28 补齐：
  > `- **建图与地图资产**：VLP-16 点云 → z 高度滤波（0.1~1.5m）→ 2D 占用网格；排查建图重影（帧率根因）后重录干净 bag（9.63Hz 零空窗）产出清洗版导航图；自研人形块过滤工具（filter_person_blobs.py）剔除建图在场人员`

### 6. 【A 版·中优先】RL 条目补"结论"，否则等于列超参

- 问题：C1/C2 现在只有"512 并行 / 22.8 万轮 / 2048 并行 / 1024 万 Env Steps"——**并行环境数是手段不是成果**。RL 岗面试官会直接问"策略最后走得怎么样"。
- 改法：每条末尾补一句结果（**只能填池子里有出处的真实结论**；若池中确实缺，就去补一次训练复盘，把最终指标写回池子 A/C 区）：
  > 例：`…（512 并行、22.8 万轮迭代），策略在 <速度区间> 下 <跟踪误差/存活率/步态指标>`
- 若暂无指标：把措辞改成过程性事实，如"完成 <奖励项> 调优并定位 <某个失败模式>"，避免用超参冒充成果。

### 7. 【A 版·低优先】D1/D4/D6 的落点

- D1（STM32F103 20+ 子项目 / 10+ 电机 / 6+ CAN 节点）：字数有限，建议进**作品集 README**，简历只保留 MCLM 一条。
- D4/D6（传感器库、LD06/LD14P ROS 驱动经验）：并入技能区一行即可，如 `传感器接入：G354/MPU6050/MT6701/VL53L0/BMP280 驱动库；LD06/LD14P（ROS 驱动验证）`。

### 8. 【B 版·投递前必改】P3 的"验收中"口径

- L26 现为"08-26 W3 避障验收中"。内部版没问题，**对外投递版**建议改为"已完成降额参数实车避障验证（08-26）"或直接删掉日期括注。理由：HR/一面看到"验收中"会读成"没做完"。

### 9. 【两版·结构】A9 与贡献度表述

- A9（平台整合）目前只在标题与衔接句里。建议在项目 1 开头一句里明确"本人负责模块 + 交付物 + 协作边界"（团队项目缺此句是最大可信度风险）。
