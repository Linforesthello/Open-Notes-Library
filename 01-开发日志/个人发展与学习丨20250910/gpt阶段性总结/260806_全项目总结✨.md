## 二、项目谱系与总体架构

**长期目标架构**（分布式）：

```
ROS2 / 上位机（N97 / VM / 树莓派 R1）
   ↓ UART / Ethernet
通信中枢 MCU（未来下层主控）
   ↓ CAN 1M
STM32 分布式节点（电机控制 ×N）
   ↓
电机 + 编码器 + IMU
```

**R1 vs R2**:

| | R1（早期平台） | R2（当前主线） |
|:--|:---|:---|
| 底盘 | 四舵轮（转向+驱动，MT6701 转角） | 四全向轮（MCLM 直驱） |
| 上位机 | 树莓派 4B（已退役）→ N100/N97 | N97 Mini PC（Ubuntu 22.04 + Humble） |
| 状态 | 07-03 三舵实车跑通（UNIT4 电机烧毁） | Phase 0-2 完成，集成导航/感知/AI 中 |

**R2 实车链路**: N97 → CANable2 (ttyACM0) → can0 (1M) → MCLM 电机 ×4（每电机内置 STM32 节点）→ 四全向轮；G354 IMU 经 JLink OB Mini (ttyACM1) 直连；VLP-16 经交换机接 enp1s0。
