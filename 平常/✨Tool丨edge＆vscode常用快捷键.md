> 
> # 🌐 Microsoft Edge 常用快捷键
> 
> ## 🧭 标签页 & 窗口管理
> 
> - `Ctrl + T` → 新建标签页
>     
> - `Ctrl + W` → 关闭当前标签页
>     
> - `Ctrl + Shift + T` → 恢复刚关闭的标签页
>     
> - `Ctrl + Tab` → 切换到下一个标签页
>     
> - `Ctrl + Shift + Tab` → 切换到上一个标签页
>     
> - `Ctrl + 1~8` → 跳转到指定序号标签页
>     
> - `Ctrl + 9` → 跳转到最后一个标签页
>     
> - `Ctrl + N` → 新窗口
>     
> - `Ctrl + Shift + N` → InPrivate 窗口
>     
> 
> ---
> 
> ## 🔍 浏览 & 查找
> 
> - `Ctrl + L` 或 `Alt + D` → 定位地址栏
>     
> - `Ctrl + F` → 页面查找
>     
> - `Ctrl + H` → 历史记录
>     
> - `Ctrl + J` → 下载记录
>     
> - `Ctrl + R` 或 `F5` → 刷新
>     
> - `Ctrl + Shift + R` → 强制刷新（无缓存）
>     
> 
> ---
> 
> ## 🛠 开发者工具（你调 ROS Web / 调试前端时常用）
> 
> - `F12` → 打开开发者工具
>     
> - `Ctrl + Shift + I` → DevTools
>     
> - `Ctrl + Shift + C` → 选择元素模式
>     
> - `Ctrl + Shift + J` → 直接打开 Console
>     
> 
> ---
> 
> # 🧑‍💻 VS Code 常用快捷键（核心高效版）
> 
> 你现在做 ROS / Python / STM32，会大量用到下面这些。
> 
> ---
> 
> ## 🔎 搜索 & 跳转（最重要）
> 
> - `Ctrl + P` → 快速打开文件（万能入口）
>     
> - `Ctrl + Shift + P` → 命令面板（几乎所有功能入口）
>     
> - `Ctrl + F` → 当前文件查找
>     
> - `Ctrl + Shift + F` → 全局搜索
>     
> - `F12` → 跳转到定义
>     
> - `Alt + F12` → 查看定义（不跳转）
>     
> - `Ctrl + 鼠标点击` → 跳转定义
>     
> - `Ctrl + -` → 返回上一个位置
>     
> 
> ---
> 
> ## ✏ 编辑效率（写代码必备）
> 
> - `Ctrl + /` → 行注释
>     
> - `Shift + Alt + A` → 块注释
>     
> - `Alt + ↑ / ↓` → 移动当前行
>     
> - `Shift + Alt + ↑ / ↓` → 复制当前行
>     
> - `Ctrl + D` → 选中下一个相同单词
>     
> - `Ctrl + Shift + L` → 选中全部相同单词
>     
> - `Alt + 鼠标点击` → 多光标
>     
> - `Ctrl + Enter` → 在下方插入新行
>     
> - `Ctrl + Shift + Enter` → 在上方插入新行
>     
> 
> ---
> 
> ## 🧠 重构 & 代码理解（进阶）
> 
> - `F2` → 重命名变量（全局安全重命名）
>     
> - `Ctrl + Space` → 代码提示
>     
> - `Ctrl + K Ctrl + C` → 注释选中内容
>     
> - `Ctrl + K Ctrl + U` → 取消注释
>     
> - `Ctrl + Shift + \` → 跳转到匹配括号
>     
> 
> ---
> 
> ## 🧭 侧边栏 & 面板管理
> 
> - `Ctrl + B` → 显示/隐藏侧边栏
>     
> - `Ctrl + J` → 打开/关闭终端面板
>     
> - `Ctrl + ~` → 打开终端
>     
> - `Ctrl + Shift + E` → 文件资源管理器
>     
> - `Ctrl + Shift + G` → Git
>     
> - `Ctrl + Shift + X` → 插件
>     
> 
> ---
> 
> ## 🖥 终端相关（你经常跑 ROS 会用到）
> 
> - `Ctrl + C` → 停止当前运行程序
>     
> - `Ctrl + Shift + 5` → 分屏终端
>     
> - `Ctrl + PageUp/PageDown` → 切换终端
>     
> 
> ---
>
