# Open-Notes-Library

个人知识库 / Obsidian Vault

---

## 📂 结构

| 目录 | 说明 |
|---|---|
| **01-开发日志/** | 项目工作笔记 — 逐日记录 + 沉淀归档 |
| **02-平常/** | 生活/日常/杂项笔记 |
| **Attachments/** | 图片附件（Obsidian 自动存放） |
| **_archive/** | 旧数据（OneNote 导入等） |
| **_tools/** | 工具脚本/导出数据（B站收藏夹、标签治理等） |

## 📖 怎么用

- **01-开发日志/✨分天/** — 按月的逐日工作记录，是原始信息源
- **01-开发日志/✨总/** — 从逐日记录中提炼的可复用知识：项目文档、技巧、AI 记录
- **02-平常/** — 生活里遇到的各种小问题/随手记

## 🏷️ 约定

- `✨` 前缀 = 这个库的特色标记，✨开头的文件夹是核心区域
- `_` 前缀 = 辅助性内容，排序在底部
- 图片统一放在 `Attachments/`，引用时用 `![[文件名.png]]`
