##   关于astrapro摄像头每次开机需要设置usb权限
#问题/重复出现＆已解决/关于astrapro摄像头每次开机需要设置usb权限 
[ROS节点分析方法](https://chatgpt.com/c/69958d5c-dd1c-83a3-9aaf-14b3ababa4cb)

> [!NOTE]
> 
> ---
> “lin@ubuntu:~$ sudo chmod +x /dev/bus/usb/003/008
lin@ubuntu:~$ sudo chmod 666 /dev/bus/usb/003/008
lin@ubuntu:~$ 
”
> ---
> 很好，这个例子就非常典型了。  
> 你现在操作的是：
> 
> ```
> /dev/bus/usb/003/008
> ```
> 
> 这不是普通文件。  
> 这是 **设备节点（device node）**。
> 
> ---
> 
> # 一、/dev 下面的文件是什么？
> 
> 在 Ubuntu 里：
> 
> ```
> /dev/*
> ```
> 
> 不是普通文件。
> 
> 而是：
> 
> > 内核为硬件创建的“设备接口”
> 
> 你现在这个：
> 
> ```
> /dev/bus/usb/003/008
> ```
> 
> 表示：
> 
> - USB 总线 003
>     
> - 设备号 008
>     
> 
> 这是一个字符设备文件。
> 
> ---
> 
> # 二、为什么 +x 没意义？
> 
> 你执行的是：
> 
> ```bash
> sudo chmod +x /dev/bus/usb/003/008
> ```
> 
> 但：
> 
> 设备文件根本不是“可执行程序”。
> 
> 执行权限（x）对它来说：
> 
> 👉 没有任何作用。
> 
> 设备文件只用：
> 
> ```
> r 读取
> w 写入
> ```
> 
> ---
> 
> # 三、为什么 666 才有作用？
> 
> ```bash
> sudo chmod 666 /dev/bus/usb/003/008
> ```
> 
> 等价于：
> 
> ```
> rw-rw-rw-
> ```
> 
> 意思是：
> 
> > 所有人都可以读写这个设备
> 
> 这对 USB 相机 / 串口 / 激光雷达 很常见。
> 
> 因为很多 ROS 驱动需要：
> 
> ```
> rw
> ```
> 
> 而不是执行权限。
> 
> ---
> 
> # 四、关键问题：为什么你要改它？
> 
> 我猜你是遇到：
> 
> ```
> Permission denied
> ```
> 
> 访问 USB 相机？
> 
> 比如：
> 
> - 深度相机
>     
> - RealSense
>     
> - Astra
>     
> - 串口设备
>     
> 
> 这是 Linux 默认安全机制：
> 
> USB 设备默认只给 root 访问。
> 
> ---
> 
> # 五、但这里有个重要问题 ⚠️
> 
> 你这样做：
> 
> ```bash
> chmod 666 /dev/bus/usb/003/008
> ```
> 
> 是临时的。
> 
> 一旦：
> 
> - 拔插 USB
>     
> - 重启系统
>     
> 
> 设备号会变：
> 
> ```
> 003/009
> 003/010
> ```
> 
> 权限会恢复。
> 
> ---
> 
> # 六、正确做法：写 udev 规则（工程方式）
> 
> 而不是每次手动 chmod。
> 
> 创建规则文件：
> 
> ```bash
> sudo nano /etc/udev/rules.d/99-usb.rules
> ```
> 
> 写入（示例）：
> 
> ```
> SUBSYSTEM=="usb", MODE="0666"
> ```
> 
> 或者更精确：
> 
> ```
> SUBSYSTEM=="usb", ATTR{idVendor}=="xxxx", ATTR{idProduct}=="xxxx", MODE="0666"
> ```
> 
> 保存后：
> 
> ```bash
> sudo udevadm control --reload-rules
> sudo udevadm trigger
> ```
> 
> 以后自动生效。
> 
> ---
> 
> # 七、为什么执行权限不行（核心回答）
> 
> 因为：
> 
> ```
> x = 允许执行程序
> ```
> 
> 而：
> 
> ```
> /dev/bus/usb/xxx/xxx
> ```
> 
> 不是程序。
> 
> 是设备接口。
> 
> 设备访问需要的是：
> 
> ```
> r = 读数据
> w = 写数据
> ```
> 
> ---
> 
> # 八、你现在其实碰到了一个重要概念
> 
> Linux 中有三类文件：
> 
> ```
> - 普通文件
> - 目录
> - 设备文件
> ```
> 
> 查看类型：
> 
> ```bash
> ls -l /dev/bus/usb/003/008
> ```
> 
> 你会看到：
> 
> ```
> crw-rw-r--
> ^
> ```
> 
> 前面的 `c` 表示：
> 
> > character device
> 
> 不是可执行文件。
> 
> ---
> 
> # 九、给你一个更成熟的理解
> 
> chmod +x 适用于：
> 
> - shell 脚本
>     
> - Python 脚本
>     
> - 二进制程序
>     
> 
> chmod 666 适用于：
> 
> - 设备接口权限开放
>     
> 
> 它们解决的是完全不同的问题。
> 
> ---
> 
> # 十、顺便问一句
>

>

>     
> - 还是 RealSense？
>     
>
